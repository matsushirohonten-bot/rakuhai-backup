# 別のPCで楽配くん自動復元を使うときの手順

このドキュメントを**別のPCに渡す人**または**受け取った人**が参照してください。  
クレジット・時間の節約のため、AIに聞く前にここを読んでください。

---

## 1. このツールでできること

- 楽配くん10の**参照用データ**を、本店の**自動バックアップ（毎日17時）**から復元する
- **手動実行**：ダブルクリックでその場で復元
- **予約実行**：毎日指定時刻（例：19時）に自動で復元

---

## 2. 事前にそろえておくもの

| 項目 | 内容 |
|------|------|
| OS | Windows 10/11 |
| 楽配くん10 | インストール済みであること |
| デスクトップショートカット | **「楽配くん参照用」** という名前のショートカットがデスクトップにあること（参照用DBを開く用） |
| AutoHotkey v2 | 後述の手順でインストール |

---

## 3. ファイルの入手方法

### 方法A：GitHubから（推奨）

1. https://github.com/matsushirohonten-bot/rakuhai-backup を開く
2. 緑の「Code」→「Download ZIP」でダウンロード
3. ZIPを解凍して、好きなフォルダに置く（例：`C:\rakuhai-backup`）

### 方法B：USBなどでフォルダごとコピー

- 既に動いているPCの `rakuhai-backup-cursor` フォルダをそのままコピー
- **コピー先PCでは `rakuhai-pos.ini` を必ず削除する**（座標はPCごとに違うため）

---

## 4. 初回セットアップ（必ず1回だけやる）

### 4-1. AutoHotkey v2 を入れる

1. 入手したフォルダ内の **`install-autohotkey-v2.ps1`** を右クリック
2. 「PowerShellで実行」を選ぶ（またはダブルクリックでOKの場合はそのまま実行）
3. 画面の指示に従って AutoHotkey v2 をインストール

### 4-2. 座標を教える（5箇所）

1. **楽配くんを起動して、メインメニュー画面を表示した状態にする**
2. **`rakuhai-auto-restore.ahk`** をダブルクリック
3. 画面の指示に従い、次の5箇所で「マウスを置いて Enter」を押す：

| 順番 | 指示される場所 |
|------|----------------|
| 1 | **「特殊処理」** ボタン |
| 2 | **「バックアップ／復元処理」** ボタン |
| 3 | **「自動バックアップ一覧」** タブ |
| 4 | 一覧の **1行目（一番上の行）** |
| 5 | **「復元」** ボタン |

4. 座標は `rakuhai-pos.ini` に保存される（このファイルは**このPC専用**。別PCにコピーしない）

### 4-3. 設定画面で好みを設定（任意）

1. **`rakuhai-settings.ahk`** をダブルクリック
2. 必要に応じて設定：
   - 「復元してよろしいですか？」を自動で「はい」にする … ON推奨
   - 予約時刻あり … 使うならON、時刻を指定（例：19時00分）
   - 予約時刻に楽配くんを使っているとき … 「スキップ」または「そのまま実行」
3. 「保存して閉じる」を押す
4. 予約を使う場合は **「予約をタスクに登録」** を押してタスクスケジューラに登録

---

## 5. 普段の使い方

| やりたいこと | 操作 |
|--------------|------|
| 今すぐ復元する | `rakuhai-auto-restore.ahk` をダブルクリック |
| 設定を変える | `rakuhai-settings.ahk` をダブルクリック → 「今すぐ復元実行」を押すと設定画面は最小化されて復元が始まる |
| ログを確認する | 設定画面の「ログを見る」、または `rakuhai-restore-log.txt` を開く |

---

## 6. 重要なルール（事故防止）

- **メインメニュー以外の画面**（宅配先情報保守・基本処理・特殊処理・データ出力メニューなど）で実行すると、**復元はスキップ**されます（デスクトップを誤クリックするのを防ぐため）
- 手動で復元するときは、楽配くんを**メインメニュー画面**にしてから実行する
- 予約実行のとき、楽配くんが別の画面のままでも**スキップ**されるだけなので安全

---

## 7. トラブル時によくある原因

| 現象 | 確認すること |
|------|----------------|
| 「Script file not found」 | スクリプトのフォルダパスが変わっていないか。タスクスケジューラの「プログラム」のパスが正しいか |
| 「特殊処理画面が開きませんでした」 | 画面の位置や解像度が変わっていないか。`rakuhai-pos.ini` を削除して、4-2の座標設定をやり直す |
| 予約時刻に何も起きない | タスクスケジューラに登録済みか。設定画面で「予約をタスクに登録」を押したか |
| 楽配くんが起動中なのにスキップされる | 設定で「そのまま実行する」になっているか。メインメニュー画面かどうか（別画面だとスキップされる） |

## 8. ファイル一覧（渡すときに含めるもの）

- `rakuhai-auto-restore.ahk` … メインスクリプト
- `rakuhai-settings.ahk` … 設定画面
- `rakuhai-config.ini` … 設定（コピーしてOK）
- `install-autohotkey-v2.ps1` … AHK v2 インストール用
- `README.md` … 概要
- `引き継ぎ書.md` … かんたんセットアップガイド
- **`rakuhai-pos.ini` は渡さない**（受け取った側で削除して、そのPCで座標を再取得する）
- **`rakuhai-restore-log.txt`** は渡しても渡さなくてもよい（ログはそのPCで新たに作られる）
