## 主な教訓（概要）

1. **楽配くん10はAccess製のMDIアプリ**
   - 親ウィンドウ「楽配くん10」と子ウィンドウ「メインメニュー」が別々
   - `WinMove` は親ウィンドウに対して行う
   - 画面判定は子ウィンドウの存在でチェック

2. **座標は手動キャプチャ方式**
   - ウィンドウを左上(0,0)に移動してから座標を取得
   - 実行時も同じ位置に移動してからクリック

3. **設定・座標ファイルはINI形式**
   - `IniWrite` / `IniRead` で上書き保存
   - `FileAppend` は重複やパースエラーの原因になる
